## 项目

### 研究与算法

- [DECAT](https://github.com/WenNinghan/DECAT) · 用分子结构和实验条件预测臭氧反应速率。我是这项工作的共同第一作者。
- [HEOA](https://github.com/WenNinghan/HEOA) · 复现人类进化优化算法，用三杆桁架设计比较约束处理方法。
- [EvoOpt](https://github.com/WenNinghan/EvoOpt-Surrogate-Bench) · 比较评估次数有限时，不同优化算法能找到怎样的解。
- [NetControl](https://github.com/WenNinghan/NetControl-Pinning-Lab) · 研究复杂网络中控制节点的选择与牵制控制。
- [HigherOrder](https://github.com/WenNinghan/HigherOrder-Simplicial-Lab) · 在网格上识别环路、补全缺失的边信号。
